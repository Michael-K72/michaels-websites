# Michael Kalachin — Digital Website Concepts

Premium interactive portfolio showcasing five original website directions:

| Concept | Industry |
|---------|----------|
| **Aura** | Luxury real estate |
| **Velora** | Premium automotive |
| **Monolith** | Architecture |
| **Nova** | Technology / AI |
| **Élan** | Luxury hospitality |

These are **interactive style concepts**, not prior client case studies.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Motion + Lenis (+ GSAP where used)
- Strict concept-specific art direction

## Develop

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```
